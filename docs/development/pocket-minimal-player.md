# 最小MDXプレイヤー 連続再生の実機確認（r2）

対象は Firmware 2.6、core `0.14.0-player-r2`、音声インターフェースHYB2です。
CPUのMXDRV／PCM8とFPGAのFMを使い、M3U順の連続再生と5秒フェードを追加しました。

## インストール

すでにr1で27曲のM3U曲集を使っている場合:

1. `minimal-player-r2-update.zip` をPCで展開します。
2. `Cores`、`Assets`、`Platforms` をSDカードの同名フォルダーへコピーします。
   更新用ZIPには曲集の `playlist.hpl` が入っていないため、取り込んだ曲集が残ります。
3. Pocketで `RPCMP.MinimalPlayer` を開き、`Playlist.json` を選びます。
4. 曲一覧が表示され、Aを押すまでは無音であることを確認します。
   起動時にAを押しっぱなしでも再生は始まりません。一度離して押してください。

最初から導入する場合や、以前の6曲で確認する場合は `minimal-player-r2.zip` を使います。
こちらには6曲の `playlist.hpl` が含まれるため、同じ場所の曲集は置き換わります。
曲名は同梱の `曲目一覧.md` を参照してください。`試聴用` のWAVはPC参照エンジンの
冒頭部分で、Pocket録音ではありません。

FPGAと起動ROM・アプリは、この候補の組み合わせで更新してください。
PCのM3U取り込み方法とHPL1曲集形式は同じです。

## 操作と連続再生

| 操作・状態 | 動作 |
| --- | --- |
| 上下 | 一覧の曲を選択。長押しで連続移動 |
| 左右 | 13曲ずつページ移動。端では止まる |
| A | 選択曲を先頭から再生し、その曲からM3U順に続ける。再生中も切り替え可能 |
| B | 停止し、自動送りも解除。一覧の選択位置を保持 |
| ループ曲 | イントロ1回＋ループ部分2周の後、FM・PCMとも5秒でフェードして次曲へ |
| 自然に終わる曲 | 1回で次曲へ。最後の曲を終えると停止 |
| 曲単位のエラー | その曲を飛ばす。残りがすべてエラーでも末尾で停止 |

一覧を移動するだけでは再生順は変わりません。選択行の背景色と再生中の曲の左端の印は
独立しています。自動で次曲へ進んでも、カーソルと表示ページは動きません。
画面下には再生中の曲名を表示します。次曲の読み込み中は一旦無音になります。
一時停止・ループ設定の切り替え・シャッフル・設定保存は今回の対象外です。

## 確認してほしいこと

1. 起動時の無音、日本語の曲名、M3U順の一覧、上下・左右の操作を確認します。
2. 途中の曲をAで選び、次の曲へ自動で進むことを確認します。
3. ループが分かる曲で、イントロ1回＋2周の後に約5秒かけて音が消えることを確認します。
   PCMのある曲では、FMとPCMの両方がフェードするか確認してください。
4. 自然に終わる曲があれば、繰り返さず次曲へ進むことを確認します。
   最後の曲をAで選び、終了後に先頭へ戻らず停止することも確認します。
5. 再生中に一覧で別の曲を探し、そのまま自動送りを待ちます。
   選択位置・ページは動かず、再生中の印と画面下の曲名が切り替わることを確認します。
6. 再生中またはフェード中にAで別の曲へ切り替え、その曲から順に進むことを確認します。
   Bで止めた後は次曲が始まらず、次のAで選択曲の先頭から再生することを確認します。
7. FM・PCM・左右の音、一覧操作中の音切れ・プチプチ音・入力遅延を確認します。
8. 通常再起動と電源OFF後の起動でも、無音で一覧に戻り、Aで再生できるか確認します。

エラー送りは自作の異常データを使うホスト試験でも確認します。手元の曲を壊す必要は
ありません。実機でエラーが出た場合は、飛ばして次曲へ進むかを記録してください。
対象の曲や状況がない項目は「対象なし」と記載してください。

停止後の `R / F / D / V / Q` は、最大音声生成・FIFO転送・描画片・画面提示時間
（us）と最小キュー残量（62.5kHzのフレーム数）です。R/F/Qは直近の再生、D/Vは
起動後の最大値です。表示は画面更新時の値です。

`SKIP` は今回の連続再生で飛ばした曲数、`#` は最後に失敗した曲の番号です。
`E1` は曲データの読み込み・検査、`E2` はエンジン、`E3` は音声装置、`E4` は供給待ちの
タイムアウトです。Aで新しく再生を始めると、前回のSKIP記録は消えます。
`E5` は音声リセット失敗なので停止します。コアを再起動してください。
起動時の `Playlist load failed` は曲集自体を読めない状態です。コピー内容を確認してください。

```text

曲数 / 起動時の無音 / 日本語の曲名:
```

## 開発者向けパッケージ生成

検証済みの準備済みMDX/PDXと `tracks.json` を指定します。

```powershell
python -B tools/pocket_hybrid_package.py --shell out/build/continuous-candidate-r2 --cpu out/build/minimal-player-cpu-r2 --firmware out/build/continuous-firmware-r2/src/firmware/os/bld/pocket --tracks out/build/hybrid-real-inputs-r2/prepared/tracks.json --output out/build/minimal-player-r2
```

出力先は未使用の名前を指定します。全体ZIPと曲集を含まない更新用ZIPを生成します。
全体ZIPには私有楽曲を含むため、ローカルでの実機確認用です。
