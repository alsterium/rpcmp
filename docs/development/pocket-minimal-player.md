# 最小MDXプレイヤー 実機確認（r1）

対象は Firmware 2.6、core `0.13.0-player-r1` です。
CPUのMXDRV／PCM8とFPGAのFM再生はHYB1 r3と同じ構成です。
曲集の読み込みと日本語の曲一覧を追加しました。今回確認するのは画面操作と再生の統合です。

## インストール

1. `minimal-player-r1.zip` をPCで展開します。
2. `Cores`、`Assets`、`Platforms` をSDカードの同名フォルダーへコピーします。
   コア名は `RPCMP.MinimalPlayer` で、以前のHybridProbeとは別に選べます。
3. Pocketでこのコアを開き、`Playlist.json` を選びます。
4. 曲一覧が表示され、Aを押すまでは無音であることを確認します。
   起動時にAを押しっぱなしでも再生は始まりません。一度離して押してください。

曲集には前回確認した6曲を同じ順序で収録します。詳しくは同梱の `曲目一覧.md` を参照してください。
`試聴用` のWAVはPC参照エンジンの冒頭部分で、Pocketの録音ではありません。

## 操作

| 操作 | 動作 |
| --- | --- |
| 上下 | 曲を選択。長押しで連続移動 |
| 左右 | 13曲ずつページ移動。端では止まる |
| A | 選択した曲を先頭から再生。再生中も別の曲へ切り替え可能 |
| B | 停止。曲一覧と選択位置は維持 |

一覧を移動するだけでは再生中の曲は変わりません。選択行に背景色がつき、現在の曲名が
画面下にも表示されます。一時停止・シャッフル・設定保存はこの版にはありません。
曲が終了したら停止し、次曲へは自動で進みません。ループと終了の扱いは確認済みの
エンジンのままです。次曲の読み込み時には一旦無音になります。

## 確認してほしいこと

1. 6曲を上下で選べること、日本語の曲名が表示できることを確認します。
2. 各曲でAを押し、旋律・テンポ・左右・PCMが前回と同じように聞こえるか確認します。
3. PCMのある曲を約1分再生しながら上下・左右を操作します。
   音切れ・プチプチ音や、一覧の入力遅延がないか確認します。
4. 再生中に別の曲へAで切り替え、Bで停止し、再度Aで先頭から再生します。
5. 通常再起動と電源OFF後の起動で一覧へ戻り、自動再生せず、Aで再生できるか確認します。

停止後、最下段の `R / F / D / V / Q` を記録してください。
Rは最大音声生成時間、Fは最大FIFO転送時間、Dは最大描画片の時間、Vは最大画面提示時間
（すべてus）、Qは観測された最小キュー残量（62.5kHzのフレーム数）です。
R/F/Qは直近の再生、D/Vは起動後の最大値です。表示は画面更新時の値です。

エラー表示の `E1` は曲データの読み込み・検査、`E2` はエンジン、`E3` は音声装置、
`E4` は供給待ちのタイムアウトです。曲を選びAで再試行できます。
`E5` は音声リセット失敗なのでコアを再起動してください。
起動時の `Playlist load failed` は曲集自体を読めない状態です。コピーしたファイルを
確認して再起動してください。

```text
Firmware: 2.6 / Minimal Player r1
起動 / A前は無音 / 勝手に再生しない:
6曲の一覧 / 日本語表示 / 上下・左右:
各曲の音楽 / 左右 / PCM:
再生中の一覧操作 / 音切れ・ノイズ / 入力の遅れ:
再生中Aで別の曲へ / B停止 / Aで先頭から:
停止後 R / F / D / V / Q:
通常再起動 / 電源OFF後:
エラー番号や気になったこと:
```

## 開発者向けパッケージ生成

既存の準備済み `tracks.json` に、表示名 `title`、同じディレクトリ内のMDXドライバー
形式ファイル `mdx`、必要なら `pdx`、任意で比較WAVの `reference` を指定します。
順序はJSON配列の順です。1〜300曲、1曲のMDX＋PDXは合計16MiB、曲集全体は512MiB以内。
曲名はUTF-8の96バイト以内に収め、長い場合は文字境界で省略記号を付けます。
元のMDXやM3Uを直接指定する形式ではありません。

```powershell
python -B tools/pocket_hybrid_package.py --shell out/build/hybrid-candidate-r3 --cpu out/build/minimal-player-cpu-r1 --firmware out/build/hybrid-firmware-20260921/src/firmware/os/bld/pocket --tracks out/build/hybrid-real-inputs-r2/prepared/tracks.json --output out/build/minimal-player-r1
```

出力先は未使用の名前を指定します。元の6曲・比較WAV・以前のパッケージは変更しません。
私有楽曲を含むため、このパッケージはローカルでの実機確認用です。
