# 最小MDXプレイヤー UI操作の実機確認（r6）

対象は Firmware 2.6、core `0.18.0-player-r6`、音声インターフェースHYB4です。
合格済みr5の再生を基準に、一覧・再生情報・操作アイコンを整理しました。
r6の操作感、経過時間、長い曲名のスクロール中の音声を確認します。

## インストール

現在のr5曲集を使う場合:

1. `minimal-player-r6-update.zip` を展開します。
2. コアを終了し、Cores・Assets・PlatformsをSDの同名フォルダーへ上書きコピーします。
3. PocketでRPCMP.MinimalPlayer → Playlist.jsonを開きます。
4. プレイリスト一覧が出て、無音・2周設定であることを確認します。

更新用ZIPには曲集が入っていません。r5のHPL2曲集はそのまま使え、取り込み直しは不要です。
以前確認した6曲で試す場合は `minimal-player-r6.zip` のCores・Assets・Platformsをコピーします。
全体ZIPには「01_確認曲」「02_ページ確認」「03_別リスト」の3リスト・42登録があります。
「02_ページ確認」は同じ6曲を繰り返した30登録です。全体ZIPの `playlist.hpl` は現在の曲集を
置き換えるため、自分の曲集を残す場合はコピー前に保管してください。
曲目は同梱の `曲目一覧.md` を参照。試聴用WAVはPC参照エンジンの音声で、Pocket録音ではありません。

自分のM3Uから新しく作る場合は [取り込み手順](m3u-library.md) を使います。
r1〜r4のHPL1曲集は読み込めないので、現在のツールでHPL2曲集を作ってください。
規模確認用の `minimal-player-r5-scale-data.zip` も引き続き使えます。

## 画面と操作

主表示は一覧、下部左は再生情報、下部右は操作パネルです。
明るい枠が操作対象のパネルです。カーソルと再生中の印は別で、別リストを閲覧しても
下部の曲名・再生元リスト・曲番号／曲数・経過時間・状態は再生対象を示します。
選択中の長い名前だけ、約1秒待って横に流れます。その他の長い名前は末尾を省略します。

| 入力 | 一覧 | 操作パネル |
| --- | --- | --- |
| 上下 | 項目選択。長押しで連続移動 | 上下のアイコンへ移動 |
| 左右 | 13件ずつページ移動。端で停止 | 左右のアイコンへ移動 |
| A | リストを開く／選択曲を先頭から再生 | 選んだアイコンを実行 |
| B | 曲一覧からリスト一覧へ戻る。音楽は継続。リスト一覧では何もしない | 再生を停止し、自動送りを解除 |
| L または R | 操作パネルへ切替 | 一覧へ切替 |
| X / Y | 割り当てなし | 割り当てなし |

L/Rのどちらでもパネルを往復できます。長押しでは切り替えを繰り返しません。
戻る行は廃止しました。リストごとの選曲位置・ページと、最後に選んだ操作アイコンを
起動中は記憶します。操作パネルの初期選択は再生／一時停止です。

| 操作アイコン | 動作 |
| --- | --- |
| 上段左: 前の曲 | 再生元リストの前の曲を先頭から再生。一時停止中・停止中でも再生を開始 |
| 上段中央: 再生／一時停止 | 再生中は一時停止、休止中は同じ位置から再開。停止後は最後に再生した曲を先頭から再生 |
| 上段右: 次の曲 | 再生元リストの次の曲を先頭から再生。一時停止中・停止中でも再生を開始 |
| 下段左: 停止 | 停止し、自動送りを解除 |
| 下段右: ループ回数 | 2周→3周→5周→無限→2周。停止・選曲・リスト切替でも保持 |

初回再生は曲一覧のAで行います。それまでは前後曲・再生アイコンは無効です。
リスト先頭の「前の曲」と末尾の「次の曲」も無効で、色が薄くなります。端から循環しません。
無効なアイコンにカーソルを置いてAを押しても、曲・位置・再生状態を変えません。
上段「次の曲」から下は「ループ回数」、下段「停止／ループ回数」から上は「前の曲／再生」です。
それ以外は配置どおり隣へ移動し、端では止まります。

曲をAで決定したときだけ再生元リストが切り替わります。閲覧中・自動送りでもカーソルは動きません。
停止後の再生アイコンと前後曲送りは、閲覧先ではなく最後に再生した曲のリストを使います。
経過時間は音声FIFOで消費された位置の秒表示です。一時停止では止まり、停止・選曲で0に戻り、
自然終了では最後の時間を保持します。全体の長さや残り時間は表示しません。

2・3・5周はイントロ1回＋指定周数の後、FM・PCMとも約5秒フェードして次曲へ進みます。
自然終了する曲は1回。リスト末尾では停止し、次のリストへ進みません。
無限では同じ曲を続け、自然終了した曲は先頭から繰り返します。
回数変更は現在位置を保って反映し、条件を満たせばフェード開始、満たさなくなれば音量を戻します。
一時停止中は無音・位置・フェードを保持します。
A/B/L/Rは押した瞬間だけ動作し、同時押しはB、A、パネル切替、十字キーの順に優先します。
再起動後はリスト一覧の先頭・無音・2周・初期アイコンに戻ります。

## 確認してほしいこと

1. 起動直後は無音で、日本語が表示されることを確認します。リストを開くだけでも無音です。
   初回選曲前に操作パネルの再生アイコンを押しても、勝手に曲が始まらないことを確認します。
2. 一覧で上下・左右・Bを試します。13曲ずつ表示し、戻る行はなく、Bでリスト一覧へ戻ります。
   リストを開き直すと元の曲・ページに戻り、リスト一覧のBは何もしないことを確認します。
3. L/Rをそれぞれ押し、どちらでも一覧と操作パネルを往復できることを確認します。
   枠と選択表示が変わり、戻ったときに元の行・アイコンを覚えていることを確認します。
   L/R長押しで繰り返し切り替わらず、X/Yでは何も起きないことも確認します。
4. FM曲・PCM曲を再生し、下部の曲名・リスト名・曲番号／曲数・時間・状態を確認します。
   別リストを閲覧しても下部は再生中の曲のままです。約10秒聴いて時間の進み方を確認します。
5. 操作パネルの再生／一時停止アイコンで約1分休止します。無音で経過時間も止まり、
   同じ位置から再開することを確認します。Bまたは停止アイコンで停止し、
   再生アイコンで最後の曲を0秒から再生することを確認します。
6. 別リストを閲覧したまま前後曲アイコンを使い、再生元のリスト内で切り替わることを確認します。
   一時停止・停止からも次の曲の再生が始まります。先頭・末尾では無効な方向を押しても変化しません。
7. ループアイコンで2→3→5→無限を切り替えます。フェード・自動送り・リスト末尾の停止、
   一時停止中の設定変更、停止・選曲後の設定保持が以前どおりか確認します。
   自動送りでは閲覧中のカーソル・ページを保持し、下部情報と再生印だけが更新されます。
8. 長い英数字の名前など、一覧の幅を超える名前があれば選択して待ちます。
   選択行だけ流れ、文字が枠外へはみ出さないことを確認します。
   該当する名前がなければ「対象なし」で構いません。
9. PCMを約1分再生しながらパネル切替・一覧移動・名前スクロールを試します。
   FM/PCM・左右・音切れ・ノイズ・入力遅延を確認し、停止後のR/F/D/V/Q/Iを記録します。
10. 通常再起動・電源OFF後に、無音・2周・閲覧位置リセットで起動することを確認します。

曲単位のエラーが出た場合だけ、同じリスト内で飛ばして次曲へ進むか記録してください。
対象の曲や状況がない項目は「対象なし」と記載してください。手元の曲を壊す必要はありません。

## 計測値とエラー

R/F/D/Vは最大音声生成・FIFO転送・描画片・画面提示時間（us）、Qは最小キュー残量
（62.5kHzのフレーム数）、Iは起動時の曲集読み込み・検査時間（ms）です。
R/F/Qは直近の再生、D/Vは起動後の最大値、Iは起動時の値です。停止後に記録してください。

エラーは一覧を覆わず下部に表示します。「スキップ」は飛ばした曲数、#は最後に失敗した
曲の曲集内番号です。E1は曲データ読み込み・検査、E2は音源処理、E3は音声出力、
E4は応答待ち失敗です。再生開始でスキップ記録を消します。
「音声リセット失敗」はコアを再起動してください。
起動時のPlaylist load failedは、曲集の破損・読み込み失敗・HPL1などが原因です。
現在の取り込みツールが作ったHPL2か確認してください。

## 開発者向けパッケージ生成

準備済みマニフェストはnameとtracksを持つリストの配列です。
MDX/PDXと参照WAVの相対パスはマニフェストのフォルダー内を指します。

```powershell
python -B tools/pocket_hybrid_package.py --shell out/build/repeat-candidate-r4 --cpu out/build/minimal-player-cpu-r6 --firmware out/build/repeat-firmware-r4/src/firmware/os/bld/pocket --tracks out/build/multiple-playlist-inputs-r5/tracks.json --output out/build/minimal-player-r6
```

合格済みr4のFPGA・起動ROM・OSとr5のHPL2曲集を再利用し、アプリをr6へ更新します。
出力先は未使用の名前を指定します。全体ZIPと曲集を含まない更新用ZIPを生成します。
全体ZIPと規模確認データは私有楽曲を含むためローカル確認用です。
