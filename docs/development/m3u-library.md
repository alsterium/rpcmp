# M3UからPocket用の曲集を作る

M3UにMDXの順番を書き、PCで必要なPDXもまとめて専用データに変換します。
Pocketは生成したHPL1曲集を読みます。Python 3.11以降が必要です。

## M3Uを用意する

音楽フォルダーにUTF-8の `playlist.m3u8` を作ります。BOMありでも使えます。
パスはM3Uのあるフォルダーからの相対パスです。スラッシュと円記号／バックスラッシュを
使えます。空白行と `#` で始まる行（EXTINFを含む）は無視します。

```m3u
#EXTM3U
作品A/01.mdx
作品A/02.mdx
作品B/テーマ.mdx
```

曲順と重複は記載どおりです。PDXはM3Uに書きません。MDX内の参照名から、MDXと同じ
フォルダーのPDXを探します。拡張子・大文字小文字の違いに対応しますが、候補が複数ある
場合は勝手に選ばず、その曲を除外します。表示名はMDX内の曲名、読めない・空ならファイル名です。

## 変換する

このリポジトリのフォルダーで実行します。

```powershell
python -B tools/m3u_import.py "C:/Users/new03/Documents/mdx/playlist.m3u8" --output out/build/my-playlist
```

古いShift-JISのM3Uは `--encoding cp932` を付けます。
M3Uより上のフォルダーにある曲も含める場合は `--root "C:/Users/new03/Documents/mdx"` を
指定します。すべてのMDX・PDXとリンク先はこのルート内に置いてください。
共有PDXが別フォルダーにある場合は `--pdx-dir "共通PDX"` を追加します。M3Uからの相対パス、
またはルート内の絶対パスで指定でき、複数回指定できます。MDXの隣を優先して探します。

1〜300曲、MDX＋PDXは展開後の内部ヘッダー込みで1曲16MiB、曲集は512MiBまでです。
M3Uは1MiBまで。元ファイルは変更しません。LZX圧縮にも対応します。
曲名が長い場合はUTF-8の96バイトに収まる位置で省略します。
壊れた外側の構造・範囲を検査しますが、すべての演奏命令の正常性を保証する検査ではありません。

出力先は毎回未使用の名前にします。既存フォルダー・ZIPは上書きしません。
読めない曲は除外し、`取り込み結果.txt` と `取り込み結果.json` にM3Uの行番号・理由を残します。
取り込めた曲があれば残りで作成します。0曲なら結果のみを出し、曲集とZIPは作りません。

## Pocketへコピーする

1. 合格済みの **Minimal Player r1** を先にSDへ入れておきます。
2. Pocketのコアを終了し、SDをPCへ接続します。
3. 生成された `my-playlist.zip` を展開します。
4. 中の **Assets** をSDの同名フォルダーにコピーし、`playlist.hpl` を置き換えます。
5. Pocketで `RPCMP.MinimalPlayer` → `Playlist.json` を開きます。

ZIPは曲集の差し替え用です。コア・OS・再生プログラムは含みません。
現在は一つの曲集を入れ替える方式です。前の曲集へ戻すには、そのAssetsをコピーし直します。

## 確認する

M3Uの順番と曲名が一覧に反映され、上下で選曲、Aで再生、Bで停止できることを確認します。
PCM曲の打楽器・サンプル音と左右の音、再生中の一覧操作も確認してください。
実機へのコピー前に除外理由を読み、意図した曲が入っているか確認します。

```text
Firmware: 2.6 / Minimal Player r1 / M3U取り込み
取り込み曲数 / 除外曲数:
M3Uどおりの曲順 / 日本語の曲名:
FM / PCM / 左右:
再生中の一覧操作 / 音切れ・ノイズ:
Aで曲切替 / B停止 / Aで先頭から:
エラーや気になったこと:
```
