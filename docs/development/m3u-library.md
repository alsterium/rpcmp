# 複数M3UからPocket用の曲集を作る

M3Uごとに1プレイリストを作り、PCでMDXと必要なPDXをまとめて専用データに変換します。
対象は **Minimal Player r5〜r7 / HPL2**、Python 3.11以降です。
r5・r6からr7への更新では、既存HPL2曲集の取り込み直しは不要です。
r1〜r4のHPL1曲集は読み込めません。元のM3Uから作り直してください。
元のMDX・PDX・M3Uは変更しません。

## M3Uを用意する

UTF-8のM3U/M3U8を使います。BOMありでも使えます。古いShift-JISなら変換時に
`--encoding cp932` を付けます。曲のパスは、それぞれのM3Uがあるフォルダーからの相対パスです。

```m3u
#EXTM3U
作品A/01.mdx
作品A/02.mdx
作品B/テーマ.mdx
```

スラッシュと円記号／バックスラッシュを使えます。空白行とコメント行（EXTINFを含む）
は無視します。PDXはM3Uに書かず、MDX内の参照名から自動解決します。
MDXの隣を優先し、大文字小文字・拡張子の違いに対応します。候補が複数ある場合は
勝手に選ばず、その曲を除外します。曲名はMDX内の名前、読めない・空ならファイル名です。

## 取り込む

リポジトリのフォルダーで実行します。複数M3Uは指定した順に並びます。

```powershell
python -B tools/m3u_import.py "C:/Users/new03/Documents/mdx/01_FM.m3u8" "C:/Users/new03/Documents/mdx/02_PCM.m3u8" --output out/build/my-playlists
```

フォルダー直下のM3Uを一括取り込みする場合:

```powershell
python -B tools/m3u_import.py --playlist-dir "C:/Users/new03/Documents/mdx/playlists" --root "C:/Users/new03/Documents/mdx" --output out/build/my-playlists-batch
```

一括取り込みはファイル名の番号順（1、2、10）です。下位フォルダーは探索しません。
個別指定と一括指定を併用すると、個別指定分の後に一括分を追加します。
プレイリスト名はM3Uファイル名から拡張子を除いたもの。日本語に対応し、同名でも
別リストとして扱います。各リストの曲順・重複はM3Uどおりです。

`--root` は読み取りを許す音楽フォルダーです。省略時は各M3Uのあるフォルダーが境界に
なります。上位や別フォルダーの曲を参照する場合は、共通の親を明示してください。
MDX・PDXとリンク先はすべてその内側に置きます。
共有PDXは `--pdx-dir "共通PDX"` で追加でき、複数回指定可能です。
相対指定は各M3Uのフォルダー基準、絶対指定もroot内に限ります。

上限は100プレイリスト、各300曲、合計30,000登録です。M3Uは各1 MiBまで。
MDX＋PDXは展開後の内部ヘッダー込みで1曲16 MiB、生成曲集は2 GiB未満です。
同一の準備済みMDX・PDXは共有して容量を抑えますが、全曲が最大サイズでも収まるという
意味ではありません。曲集が容量上限を超えた場合は取り込みを失敗させます。
LZX圧縮に対応します。長い表示名はUTF-8の96バイトに収まる位置で省略します。

出力先は毎回未使用の名前にします。既存フォルダー・ZIPは上書きしません。
読めない曲は除外し、`取り込み結果.txt` と `取り込み結果.json` にリスト・行番号・理由を残します。
全曲除外されたリストは一覧に載せず、結果に残します。全リストが空なら結果だけを出します。
M3U自体の文字コード・曲数・サイズの不正は取り込み全体のエラーです。
外側の構造・範囲の検査は、すべての演奏命令の正常性を保証するものではありません。

## Pocketへコピーする

1. `minimal-player-r7-update.zip` を展開し、Cores・Assets・PlatformsをSDの同名フォルダーへコピーします。
2. 作成した `my-playlists.zip` を展開し、AssetsをSDへコピーして `playlist.hpl` を置き換えます。
3. PocketでRPCMP.MinimalPlayer → Playlist.jsonを開きます。
4. プレイリストをAで開き、曲をAで決定して再生します。

コピー前にコアを終了してください。曲集ZIPだけにはアプリ・コア・OSは含まれません。
r7アプリとHPL2曲集を組み合わせます。r4へ戻す場合は、保管したr4パッケージと
そのHPL1曲集を一緒に戻します。

## 確認する

取り込み結果のリスト数・曲数・除外理由を確認し、指定順・番号順・M3U内の曲順が
Pocketと一致するかを確認します。詳しい操作・実機報告は
[最小プレイヤーの確認手順](pocket-minimal-player.md)を参照してください。

```text
Firmware: 2.6 / Minimal Player r7 / M3U取り込み
取り込み方法（個別指定／一括／併用）:
プレイリスト数 / 曲数 / 除外数:
プレイリスト名・順番 / 各M3Uの曲順 / 日本語表示:
FM / PCM / 左右 / 再生中の別リスト閲覧:
リスト末尾停止 / 別リストで曲をA決定:
エラーや気になったこと:
```
