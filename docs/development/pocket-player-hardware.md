# M6 修正版r4 実機チェック

Firmware 2.6 で報告された、演奏表示の停止と画面の遅さに対応する候補です。
設定は起動ごとに **通常順／2周＋5秒フェード／シャッフルOFF** に戻り、
自動再生はしません。r3の実機報告で、左右の音声・各操作・自動送り・再起動を
確認できました。r4は表示履歴が先読みで消える問題を修正し、描画とTrackerの
処理量を削減しました。同梱テスト音源の音量指定も上げています。
これらの改善は実機未確認です。

## 導入

1. `out/build/m6-player-candidate-r4-final.zip` を展開し、`Cores`・`Assets`・
   `Platforms` をSDカードのルートへコピーします。
2. Pocket の openFPGA から **RPCMP Album Player** を選びます。
   ファイル選択が出たら `player.json` を選びます。
3. プレイヤー画面まで進むこと、勝手に音が鳴らないことを確認します。

この候補は `RPCMP.AlbumPlayer`／`rpcmp_player` 専用です。
従来のM5診断コアとは別に置けます。`Saves` は使用しません。
`core.json` の `version_required` は **2.2** を同梱済みです。
これは最低バージョンの宣言であり、Firmware 2.2での動作確認を意味しません。
Firmware 2.6で2.2への変更が必要だった、という実機報告に合わせています。
（[公式の項目説明](https://www.analogue.co/developer/docs/core-definition-files/core-json)）

SHA-256: `97f0b2c686629b4c7966c38fd704c91ab0e4bdd72ce7132c87e433241f0b7557`

## 最初に確認する操作

同梱音源は自作のFMテスト音で、2アルバム・3曲です。
FMチャンネルAだけを使用し、左右両方へ出力する指定です。
今回はまず「上昇ループ」を無限設定で再生し、音量と、Trackerの行・鍵盤の
チャンネルAが音に合わせて変化することを確認してください。B〜Hが動かない
ことは、この同梱音源では正常です。音が鳴っていても
`Waiting for performance data` が残り続ける場合は、そのまま報告してください。

1. 起動直後、エラーが出ないことを確認します。**下→左**で表示切替アイコンへ
   移り、**Aを2回**押して曲一覧に切り替え、**左**で一覧にフォーカスします。
   十字キーで選び、**A**でアルバム、さらに曲を決定します。
   最初のアルバムの「上昇ループ」から試します。
2. 音が聞こえること、左右両方から出ること、曲名・時間・チャンネルAの
   演奏表示が動くことを確認します。
3. 一覧から**右**で再生操作へ戻ります。操作パネル上段の**上**、または
   各段の先頭アイコンから**左**で主表示へ移ります。
   再生アイコン、またはTracker・鍵盤にフォーカスして **A** で一時停止／再開、
   **B** で停止します。Bを再度押しても画面・パネルは移動しません。
   一覧にフォーカスしている間のBは、再生を止めず曲一覧からアルバム一覧へ戻ります。
4. 再生しながら表示切替アイコンでTracker・鍵盤・曲一覧を切り替え、
   音が途切れないか確認します。**L/R** で前後の曲へ切り替えます。
5. ループアイコンを十字キーで選び **A** を押すと、2周→3周→5周→無限を
   切り替えます。シャッフルもアイコンで切り替え、ON/OFFの文字を確認します。

通常設定で「上昇ループ」を最後まで流すと、2周＋5秒フェードの後に
「下降・終端」へ進み、その曲が自然に終わると停止する想定です。
一時停止・表示切替・無限ループの確認は、この自動送り確認と分けて行えます。

通常再起動と電源OFF後も起動でき、変更した設定が既定値へ戻ることを
確認してください。今回は下の短い結果で十分です。100〜300曲の実曲検証や
詳しい実曲負荷の検証は、まず表示・音声が確認できてから進めます。
画面上部の `F` は前回の描画開始から表示受付までのミリ秒、`S` は音源サービスの
最大間隔（マイクロ秒）です。主表示ごとに数値を記録すると遅延を絞れます。

```text
Firmware: 2.6 / r4
音量 / 左右 / 無限ループで1分:
TrackerのチャンネルAの行が動く:
鍵盤のチャンネルAが動く / Waiting表示が消える:
再生中 Tracker F・S / 鍵盤 F・S / 一覧 F・S:
入力反映の遅れ / 表示切替中の音切れ:
一時停止・再開 / 停止 / 次曲での演奏表示:
再起動 / 以前できた操作の不具合 / エラー:
```

途中で止まった場合は、最後の画面の文字と操作をそのまま記録してください。
エラー時は本文に加え、主表示下端の2行をそのまま記録してください。
`ERR / AT / D / SND` はエラー番号・バックエンドの失敗箇所・詳細値・失敗時の
音源状態です。リセット後も最初の値を保持し、選び直した曲の準備が始まると
新しい試行に切り替わります。`REC / FLIP` は最大描画準備時間・最大表示処理時間です。
テストを通過しても、
実曲負荷での音声供給期限や既存シェルの外部タイミングまで確認済みにはなりません。
